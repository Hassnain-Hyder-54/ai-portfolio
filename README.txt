# Hassnain Hyder AI Portfolio

This package contains two versions of the portfolio website.

## Plain HTML, CSS, and JavaScript
Open `ai-portfolio-vanilla/index.html` in a browser. The project images are loaded from Unsplash and need an internet connection.

## React version
Install Node.js, then from the `ai-portfolio-react` folder run:

```sh
npm install
npm run dev
```

To create a production build, run `npm run build`.

## Personalize
Update the name, email address (`hello@example.com`), project descriptions, and links in the relevant HTML/JSX files. Update image URLs in the CSS if you want to use your own project images.
